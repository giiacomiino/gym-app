# ACL → SKI PREP

App web (PWA) de entrenamiento: fuerza post-reconstrucción de LCA y preparación para esquí, 1 oct 2026 → 15 feb 2027.

- Sin build: HTML + JS estático. Se publica con GitHub Pages.
- Las marcas de ejercicios y sesiones se guardan en el celular (localStorage). Pesos sugeridos calculados con el perfil (76 kg, 1.80 m).
- Funciona offline gracias al service worker (`sw.js`).

No sustituye la rehabilitación médica. El trabajo dinámico (cambios de dirección, saltos) entra desde la semana 8, según la estimación del doctor de 6–8 semanas de actividad.
