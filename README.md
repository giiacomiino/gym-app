# ACL → SKI PREP

App web (PWA) de entrenamiento: fuerza post-reconstrucción de LCA y preparación para esquí, 1 oct 2026 → 15 feb 2027.

- Sin build: HTML + JS estático. Se publica con GitHub Pages.
- Datos local-first (localStorage) con sincronización opcional a Supabase (`config.js` + `supabase/schema.sql`).
- Funciona offline gracias al service worker (`sw.js`).

No sustituye la rehabilitación médica. Toda progresión de impacto, saltos, carrera, cambios de dirección, movimientos explosivos o laterales rápidos depende de la autorización del traumatólogo/fisioterapeuta.
